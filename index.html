Quick Revision — مراجعة سريعة

Important Definitions

NLPمجال في الـ AI بيخلي الكمبيوتر يفهم ويحلل ويولّد اللغة البشرية. NLUفهم المعنى والنية (Intent/Entities) من النص. NLGتوليد نص طبيعي من بيانات أو معنى. Corpusمجموعة كبيرة من النصوص بنشتغل عليها. Tokenأصغر وحدة نص بنشتغل عليها (كلمة، جزء كلمة، علامة ترقيم). Tokenizationتقسيم النص لـ Tokens. Stop Wordsكلمات شائعة قليلة المعنى (the, is, and). Stemmingقص نهايات الكلمة بقواعد بسيطة للوصول لـ Stem (ممكن مايكونش كلمة حقيقية). Lemmatizationإرجاع الكلمة لأصلها القاموسي Lemma باستخدام القواميس والـ POS. Regexلغة أنماط (Patterns) للبحث والاستبدال في النص. Bag of Wordsتمثيل المستند كعدّ تكرار الكلمات مع تجاهل الترتيب. N-gramتتابع N كلمات متجاورة (Bigram = 2، Trigram = 3). TFنسبة تكرار الكلمة داخل المستند. IDFقياس ندرة الكلمة عبر المستندات؛ الكلمة النادرة وزنها أعلى. TF-IDFTF × IDF: كلمة متكررة في مستند ونادرة في الباقي = مهمة.

Formula Reference — المعادلات

TF(t, d)      = count(t in d) / total terms in d
IDF(t)        = ln( N / df(t) )          N = number of documents, df = documents containing t
TF-IDF(t, d)  = TF(t, d) x IDF(t)

scikit-learn (smoothed): IDF(t) = ln( (1 + N) / (1 + df(t)) ) + 1   then L2-normalize each row
Number of n-grams in T tokens = T - n + 1

مثال: N=3 ، الكلمة hard ظهرت في مستند واحد (df=1) وTF=1/3: IDF = ln(3/1) = 1.099 ← TF-IDF = 0.333 × 1.099 = 0.366. أما is (df=3): IDF = ln(1) = 0 ← TF-IDF = 0.

Quick Pipeline Cheat Sheet

Raw Text -> Cleaning -> Tokenization -> Normalization (lowercase, stem/lemma)
         -> Stop Words Removal -> Vectorization (BoW / TF-IDF) -> Model -> Evaluation
